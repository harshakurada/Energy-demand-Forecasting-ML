Intelligent Energy Demand Forecasting with ARIMA, SARIMA, XGBoost, and LightGBM

## Overview

This project predicts hourly electricity demand using statistical and machine learning models.

### Models Used

* ARIMA
* SARIMA
* Random Forest
* XGBoost
* LightGBM

### Evaluation Metrics

* RMSE
* MAE
* MAPE

### Key Features

* Lag Features
* Rolling Statistics
* Calendar Features
* Time-Series Forecasting

### Results

Machine learning models outperformed traditional statistical forecasting approaches, with XGBoost achieving the best overall performance.
